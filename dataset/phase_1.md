## Objective

Define one clear industry and the scope of data used across the project.

## Requirements

| Item | Requirement |
|---|---|
| Industry | Consumer Electronics & Accessories |
| Business Context | Retail / e-commerce customer consultation and support |
| Language | Vietnamese |
| Data Channels | Phone call, Zalo, Facebook Messenger, website chat |
| Logical Datasets | Policy, Catalog, Transcript |
| Product Target | 30–50 products |
| Data Source | Existing/reference data where suitable + AI-generated synthetic data |
| Multi-session Support | Required |
| Multi-channel Support | Required |
| PII | Synthetic or masked only |

## Dataset Scope

| Dataset | Purpose |
|---|---|
| Policy | Stores business rules such as payment, shipping, return, warranty, promotion, privacy, and support |
| Catalog | Stores product facts such as name, category, brand, price, stock, and specifications |
| Transcript | Stores customer interaction data across multiple sessions and channels |
