# Bug format

- Định dạng file dataset hiện tại của `01_scenarios_prefilled.jsonl` và `02_scenarios_complete.jsonl` là JSONL. Định dạng file của BTC là JSON.
  - Hướng khắc phục: Chuyển định dạng file từ JSONL sang JSON.
  - Trạng thái: Đã khắc phục.

- Trường `scenario_id` đang có format `SC-G9-xxx`, trong khi format của BTC là `SC-xx`.
  - Trạng thái: Đã khắc phục.
